# Installing Line Cook for Claude Code

## Install

```bash
/plugin marketplace add smileynet/line-cook
/plugin install line@line-cook
```

## Update

```bash
/plugin update line
```

## Verify

After installing, run:

```
/line:help
```

You should see a list of available Line Cook commands.

## Next Steps

1. Install [beads](https://github.com/steveyegge/beads): `brew install steveyegge/beads/bd`
2. Initialize beads in your project: `bd init`
3. Follow [Getting Started](../getting-started.md)
